This repository contains the STL file for a 3D-printed cover designed to fit on top of standard bumblebee rearing boxes.
The design was used to investigate the role of non-visual cues in cuckoo bumblebee host-finding and may be useful for similar behavioural choice experiments.

Citation:
Please cite the associated publication if this design is used:
Dartnell, S., Symington, H., & Dicks, L.V. (in review).
